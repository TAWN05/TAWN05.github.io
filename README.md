# TAWN05.github.io

Personal portfolio for Jacob Casey. The site highlights the Veilscope capstone project, technical skills across AI-enabled data
pipelines, and contact options for internship and collaboration opportunities.

## Development

The site is a static HTML/CSS experience. To preview locally, open `index.html` in your browser or use a lightweight HTTP server
such as:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000 in your browser.
